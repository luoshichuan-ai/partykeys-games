# 学校关 Sprite Sheet 规格

将动作表放到本目录：

- `chaser-sheet.png`：教导主任，固定 4 列 × 3 行。
- `runner-sheet.png`：学生，固定 4 列 × 2 行。

## 教导主任 4×3

从左到右、从上到下：

1. `idle_1`
2. `idle_2`
3. `run_1`
4. `run_2`
5. `combo_4_1`
6. `combo_4_2`
7. `combo_8_1`
8. `combo_8_2`
9. `win`
10. `lose`
11–12. 空白

## 学生 4×2

从左到右、从上到下：

1. `idle_1`
2. `idle_2`
3. `run_1`
4. `run_2`
5. `run_fast_1`
6. `run_fast_2`
7. `caught`
8. `escape`

每格必须等宽等高。允许透明底、白底或统一纯色背景。
