# 疯狂追追追

一个 MIDI 键盘驱动的漫画追逐小游戏原型。第一版完整实现“学校大追捕”玩法，包含 6 首 15 音符预设旋律、4 档难度、Web MIDI 输入、PartyKeys 逐键 RGB 灯光、Combo 阶段、追逐和胜负结算。

## 运行

推荐使用 Chrome 或 Edge 打开本地服务器地址，以便浏览器授权 Web MIDI：

```bash
python3 -m http.server 5173
```

然后访问 `http://localhost:5173`。

没有 MIDI 键盘时，可使用电脑键盘试玩：

- A / S / D / F / G / H / J / K：C4 / D4 / E4 / F4 / G4 / A4 / B4 / C5
- W / E / T / Y / U：对应黑键

## 当前范围

- 已完成：主菜单、难度、MIDI、随机预设旋律、倒计时、判定、Combo、追逐、胜负。
- PartyKeys 36 使用官方 SysEx 协议显示当前音符；其他支持 MIDI 回传控灯的键盘使用通用 Note On / Off 模式。
- 难度固定为 Level 1–4，逃跑速度分别为 420、560、760、1100；Level 4 带有 FINAL CHASE 视觉警报。
- Combo 仅影响视觉和追击奖励，不会改变逃跑者的持续移动速度。
- 角色使用显式动作状态：追击者 idle/run/combo_4/combo_8，逃跑者 idle/run/caught/escape；连续 Perfect 会重新触发冲刺且不会被旧计时器打断。
- 普通 Perfect 是单次冲刺后回到 idle；Combo 4/8 形态会持续循环移动，只有 Miss 清零后才回到普通 idle。
- 支持直接加载固定网格 Sprite Sheet：教导主任 4×3，学生 4×2；缺少图片或 Canvas 处理失败时自动显示原有漫画占位角色。
- Sprite Sheet 在浏览器中先经过 Canvas 像素预处理：逐格从边缘移除连通的绿幕或近白背景，保留人物内部眼白和白色衣服，再生成带 Alpha 的临时图片用于游戏和结算。
- 学校关使用固定静态校园背景图，保持原始宽高比完整显示；终点校门和指示牌直接包含在背景中。
- 第二关厨房追逐战已启用：背景保留冰箱、奶酪、宽桌面和放大的老鼠洞终点；主菜单可直接选择学校或厨房场景。
- 厨房关已接入黑猫警长与老鼠动作表，包括 idle、run、Combo 4/8、抓获、逃脱和胜负结算。
- 五个场景均已预留独立胜利/失败结算配置，学校关已接入可玩的结算小剧场。
- 已预留：厨房、快餐店、奶奶、追狗四组场景数据。
- 当前角色使用 CSS 漫画占位，后续可直接替换为整张 PNG 动作帧。
